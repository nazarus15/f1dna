# Оновлення сайту F1 DNA вручну

Автоматично сайт оновлюють заплановані задачі Claude: о 10:00 (Київ) у понеділок і вівторок після кожного Гран-прі (26–27.10, 2–3.11, 9–10.11, 23–24.11, 30.11–1.12, 7–8.12), якщо ноутбук увімкнений і застосунок Claude відкритий. Якщо запуск пропущено, приходить повідомлення. Якщо задача не спрацювала або треба оновити одразу, запусти скрипт вручну. Це займає 5 хвилин.

## Підготовка (один раз)

1. **Токен GitHub.** Створи його на https://github.com/settings/personal-access-tokens/new:
   - Repository access: *Only select repositories* → `nazarus15/f1dna`;
   - Permissions → Repository permissions → **Contents: Read and write**.

   Збережи токен у менеджері паролів. Якщо токен загубився або протермінувався, створи новий.
2. **Закладка.** У браузері, де ти залогінений у F1, створи нову закладку:
   - назва: `F1 DNA оновити`;
   - адреса (URL), одним рядком:
     ```
     javascript:fetch('https://raw.githubusercontent.com/nazarus15/f1dna/main/tools/updater.js?t='+Date.now()).then(r=>r.text()).then(c=>(0,eval)(c))
     ```

## Запуск після етапу

1. Відкрий https://fantasy.formula1.com/en/leagues/leaderboard/private/6296404 і переконайся, що ти залогінений.
2. Натисни закладку `F1 DNA оновити`. Внизу праворуч з'явиться панель «F1 DNA · оновлення сайту».
   - На першому запуску в цьому браузері панель попросить токен: встав його і натисни «Зберегти токен і запустити».
3. Зачекай, поки в панелі з'явиться результат з ✓ (до 5 хвилин). Не закривай вкладку, поки скрипт працює.
4. Відкрий https://f1predict.formula1.com/en/leagues/leaderboard/private/494410, зачекай кілька секунд, поки сторінка завантажиться, і натисни закладку ще раз. Для цього сайту токен теж треба ввести один раз.
5. Через 1–3 хвилини після повідомлення «оновлено» сайт https://nazarus15.github.io/f1dna/ покаже нові дані. Якщо сторінка стара, онови її з очищенням кешу (Ctrl+Shift+R).

## Що означають повідомлення панелі

| Повідомлення | Що робити |
|---|---|
| ✓ … оновлено до Rn | Нічого, сайт збереться сам |
| ✓ Дані … актуальні | Нових результатів немає, нічого не змінено |
| ✓ … ще не опублікував результати Rn | F1 ще рахує очки. Запусти пізніше; на сайті тим часом плашка **Pending** |
| Потрібен токен / Токен не підходить | Встав чинний токен у панель |
| Не вдалося прочитати лігу / не знайдено сесію | Увійди в F1 Fantasy або F1 Predict і запусти ще раз |
| F1 обмежує запити, пауза 60 с | Нічого, скрипт продовжить сам |
| ✗ Сума очок не збігається… | F1 ще перераховує результати. Спробуй за кілька годин |

## Як перевірити, що збірка пройшла

https://github.com/nazarus15/f1dna/actions — останній запуск «Збірка сайту» має зелену позначку. Якщо він червоний, напиши Claude «онови» — я розберусь.

## Плашка Pending

Вона з'являється на сайті окремо для F1 Fantasy та F1 Predict, якщо етап завершився понад 3 години тому, а його результатів ще немає в даних сайту. Коли дані оновляться, плашка зникне сама.
