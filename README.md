# Formula 1 DNA — F1 Fantasy і F1 Predict

Неофіційний аналітичний сайт приватних ліг «Formula 1 DNA»: F1 Fantasy (ліга 6296404) і F1 Predict (ліга 494410) від Telegram-каналу [ДНК Формули-1](https://t.me/F1DNA).

**Сайт:** відкривається через GitHub Pages з гілки `main`.

Режим F1 Fantasy: таблиця, команда, результати етапів, аналітика, суперники, сезон, календар. Режим F1 Predict: таблиця, гравець, етап, динаміка, очки і точність, рекорди, двоборство обох ліг.

Дані оновлюються скриптом `tools/updater.js` після кожного етапу, сайт збирає GitHub Action (див. `tools/README.md`). Увесь сайт — один файл `index.html` із вбудованими даними.

F1, FORMULA 1 та пов'язані знаки належать Formula One Licensing B.V. Сайт не пов'язаний з Formula 1.
